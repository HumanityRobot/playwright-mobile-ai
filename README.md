# blu Mobile Automation

Mobile automation framework for the blu UAT application using Playwright, WebdriverIO, Appium 2, Android, TypeScript, and PDFKit.

---

## Tech Stack

- Playwright Test
- WebdriverIO
- Appium 2
- Android
- TypeScript
- PDFKit
